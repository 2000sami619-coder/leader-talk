# 리더톡 — 현장 위주 리더십 챗봇

팀장이 팀원과 껄끄러운 대화를 앞두고 여는 도구.
상황을 자유롭게 적으면 비슷한 상황을 겪은 리더가 실제로 어떻게 말했고
그래서 어떻게 됐는지 보여준다.

사이클 1 (2026.8.24 ~ 9.4) · PM/빌더 규현 · DR 민수 · QAT 진솔

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 · 사례 데이터 63건 · 매칭 엔진 (한 파일) |
| `api/chat.js` | 대화 담당 서버 함수. Claude API 호출 |
| `cases-원본.json` | 데이터 원본 (검수·교체용, 배포에는 불필요) |

## 배포

1. GitHub 저장소에 위 파일을 폴더 구조 그대로 올린다 (`api/chat.js`는 api 폴더 안)
2. Vercel에서 Import → Deploy
3. Settings → Environment Variables 에 `ANTHROPIC_API_KEY` 등록
4. Deployments 탭에서 Redeploy

빌드 설정은 건드리지 않는다. 정적 파일 + 서버 함수로 자동 인식된다.

## 구조

```
사용자 입력
   ↓
[로컬] 유효성 검사 · 개인정보 마스킹
   ↓
[API] 대화 — 부족한 정보 되묻기 / 유형 판정
   ↓
[로컬] 사례 매칭 — 63건에서 검색
   ↓
결과 화면
```

대화만 API가 맡고 **사례 검색은 로컬 규칙 엔진**이 한다.
모델이 사례를 지어내지 못하게 하려는 의도적 분리다.

API 호출이 실패하면 자동으로 규칙 기반 대화로 전환된다. 서비스는 죽지 않는다.

## 비용

Claude Haiku 4.5 기준 대화 1건당 약 $0.007 (10원 안팎).
신규 가입 시 $5 무료 크레딧 제공. QAT 테스트 분량은 500원 미만.

키가 없거나 크레딧이 소진되면 규칙 기반으로 자동 전환되므로 화면은 계속 동작한다.

## 데이터 63건

- `source: real` — 설문으로 수집한 실제 리더 경험 13건
- `source: synthetic` — 실제 사례를 바탕으로 보강한 50건 (`basedOn`에 근거 ID)

전 사례를 동일한 서술 형식으로 정리했다. 개인정보는 포함하지 않는다.
